PASS if the design starts from the eight students that can be had, says what a comparison of that size can or
cannot detect (or that it should be checked with the plugin's power.py before anyone takes part), shows both
variants rather than one, fixes the prediction and kill criterion in advance, and says that a difference it cannot
detect is not evidence of no difference.

FAIL if it assumes an effect size (for example "a medium effect, d = 0.5") without a source in order to say eight
is enough, if it promises a statistically significant answer from eight people without saying what difference that
would take, or if it tests one version alone.
