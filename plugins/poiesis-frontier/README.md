# poiesis-frontier

New concepts and the experiments that could prove them wrong: the `frontier` skill frames the problem, picks a
method (first principles, lateral, systems, concepts, speculative design), and ends every concept with the
`experiment` playbook; the `experimentalist` agent designs the experiments independently.

The plugin of [Poiesis Frontier](https://github.com/gorgmihai92/poiesis-frontier), one of the four products in the
Poiesis Toolkit: Research collects, Insight connects, Frontier explores, Design creates ([Poiesis
Research](https://github.com/gorgmihai92/poiesis-research), [Poiesis
Insight](https://github.com/gorgmihai92/poiesis-insight), [Poiesis
Design](https://github.com/gorgmihai92/poiesis-design)).

```
/plugin marketplace add gorgmihai92/poiesis-frontier
/plugin install poiesis-frontier@poiesis-frontier
```

Full guide: https://github.com/gorgmihai92/poiesis-frontier#readme
