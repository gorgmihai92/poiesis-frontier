# poiesis-frontier

New concepts and the experiments that could prove them wrong: the `frontier` skill frames the problem, picks a
method (first principles, lateral, systems, concepts, design space, estrangement, recombination, speculative design
and research), checks by script what each concept starts from against Poiesis Insight's challenge stamps, and ends
every concept with the `experiment` playbook; `study.md` and `power.py` size a study to the people you have; the
`experimentalist` agent designs the experiments independently.

The plugin of [Poiesis Frontier](https://github.com/gorgmihai92/poiesis-frontier), one of the five products in the
Poiesis Toolkit: Research collects, Insight connects, Foresight anticipates, Frontier explores, Design creates
([Poiesis Research](https://github.com/gorgmihai92/poiesis-research), [Poiesis
Insight](https://github.com/gorgmihai92/poiesis-insight), [Poiesis Foresight](https://github.com/gorgmihai92/poiesis-foresight), [Poiesis
Design](https://github.com/gorgmihai92/poiesis-design)).

```
/plugin marketplace add gorgmihai92/poiesis-frontier
/plugin install poiesis-frontier@poiesis-frontier
```
